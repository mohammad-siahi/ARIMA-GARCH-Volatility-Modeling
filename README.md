# ARIMA-GARCH Volatility Modeling

ARIMA-GARCH modeling of monthly stock returns for **ENEL.MI** using R.

The project:
- Models the conditional mean with ARIMA
- Tests for ARCH effects
- Estimates a GARCH(1,1) volatility model
- Forecasts 12-month ahead conditional volatility
